# Brain Tumor Detection Using MRI Images

## Project Overview
This project uses Deep Learning techniques to detect brain tumors from MRI images. It analyzes brain MRI scans and predicts the class of an image based on the trained model.

## Objectives
- Detect brain tumors using MRI images.
- Preprocess and analyze medical images.
- Train a model for image classification.
- Explore the application of AI in healthcare.

## Technologies Used
- Python
- Google Colab
- TensorFlow / Keras
- NumPy
- Matplotlib
- OpenCV

## Dataset
The project uses a brain MRI image dataset for training and testing the model.

## Methodology
1. Load the MRI image dataset.
2. Preprocess and resize images.
3. Split the dataset into training and testing sets.
4. Build and train the model.
5. Evaluate model performance.
6. Predict the class of new MRI images.

## Expected Output
The model predicts the category of an MRI image based on the classes available in the dataset.

## How to Run
1. Open the notebook in Google Colab.
2. Upload the MRI dataset.
3. Run all cells in order.
4. Train and evaluate the model.
5. Test the model with an MRI image.

## Applications
- Medical image analysis
- AI-based healthcare research
- Deep Learning education

## Limitations
This project is for educational purposes only. It is not intended to replace professional medical diagnosis.
